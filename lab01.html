Semester Reflection

What I learned: I am starting to understand how HTML works and how a webpage is built in sections. I also learned that CSS controls more of the design, like colors, spacing, fonts, and the way the page feels to a visitor.

Challenges I overcame: The hardest part was figuring out which file I was supposed to edit and making sure my buttons connected to the right pages. I worked through it by checking the file names in my folder, saving copies when I needed to, and previewing the page before moving on.

How I grew: I feel a little more confident editing code now. I am still learning, but I understand more about how the placeholders, links, images, and sections work together.

Looking ahead: I think these skills will help me with my final project and future assignments. I want to keep getting faster and more comfortable so my portfolio feels polished, organized, and still personal to me.
