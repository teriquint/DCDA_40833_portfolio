What I Did for Lab 1

For Lab 1, I customized the starter portfolio template and made it feel more like my own site. I updated my name in the browser title, header, and footer, added my GitHub repository link, wrote my About Me section, added a profile photo, changed the color scheme, and started my semester reflection.

This lab helped me understand how a basic website is put together. I learned that HTML controls the content and structure, while CSS controls the design choices like colors, fonts, spacing, and layout. I also learned that small details matter, especially with file names, links, and where things are saved.

Portfolio Setup Checklist

  • Updated my name in the page title, header, and footer
  • Added my GitHub repository link
  • Wrote a personal About Me section
  • Added a profile photo

  • Added comments in the HTML to explain what I changed
  • Started my semester reflection section

Design Choices

I chose purple and light blue because I wanted the portfolio to still feel connected to TCU, but not feel too heavy or plain. The purple gives it a school connection, and the light blue makes the page feel softer and easier to read.

I also wanted the site to feel clean and simple. I did not want the design to distract from the actual lab work. My goal was to make the page look polished, but still easy for me to understand and edit as the semester continued.

Lab 1 Reflection

What I learned: I am starting to understand how HTML works and how a webpage is built in sections. I also learned that CSS controls more of the design, like colors, spacing, fonts, and the way the page feels to a visitor.

Challenges I overcame: The hardest part was figuring out which file I was supposed to edit and making sure my buttons connected to the right pages. I worked through it by checking the file names in my folder, saving copies when I needed to, and previewing the page before moving on.

How I grew: I feel a little more confident editing code now. I am still learning, but I understand more about how the placeholders, links, images, and sections work together.

Looking ahead: I think these skills will help me with my final project and future assignments. I want to keep getting faster and more comfortable so my portfolio feels polished, organized, and still personal to me.
